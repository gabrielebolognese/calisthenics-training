## Cloud backup (your request, 2026-10-16)

You asked for an automatic cloud backup, with IndexedDB staying the main store and the export going through the share sheet. The first version ran on Cloudflare (a Pages Function with KV, and hosting moved to Cloudflare Pages). The same day, you asked to switch to Supabase because it's easier to set up. So the backup now lives in a Supabase database, and the app stays on GitHub Pages. Your data never had to move to a new address.

The brief listed "backend" and "sync" as out of scope (§16); this request overrides that for backups only. There's still no account system and no sync between devices: one phone, plus a copy in the cloud.
